# Release 21.22.7 — Review Work + Dashboard Optimization

- Staff task-supervisor profiles (`TS-*`, including administrator task profiles) are excluded from Monthly Daily Time Record generation and lists.
- Sidebar terminology now distinguishes **Daily Task Reports (Work Activities)** from **Daily Time Record (DTR)**.
- Dashboard Availability / Assignment / Overdue member lists are compact horizontal name flows while preserving the existing theme and state colors.
- Admin/Supervisor **My Work** now includes **My Review Queue**, review status, accumulated review time, and active review timer state.
- Review work remains separate from freelancer task ownership, progress, and production Work Orders.
- No Alembic migration, schema change, or backfill is included.
