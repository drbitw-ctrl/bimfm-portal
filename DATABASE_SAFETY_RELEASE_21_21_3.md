# Database Safety — Release 21.21.3

Release 21.21.3 is a presentation-layer update only.

It does not add or modify database tables, columns, indexes, constraints, migrations, records, or background repairs. The name-visibility setting exists only in the currently displayed browser page and resets to names shown on a fresh page load.

Render rollback requires only rolling back the Web Service deployment. No PostgreSQL rollback is required for this release.
