# Database Safety — Release 21.17

Release 21.17 is an application-only update.

## Schema

```text
Alembic head: 20260804_0015
New migration: None
New tables: None
New columns: None
New indexes: None
```

## Data behavior

Deployment does not insert, update, delete, or backfill production records.

The updated utilization report performs read-only calculations from:

- Portal projects and tasks
- Task assignments
- Work Schedule and holidays
- Daily Task records generated by Work Orders or entered through the supported workflow

The Recently Completed Tasks period selector applies read-only query filters to existing completed tasks.

## Calculation change

Historical completion-date estimates are no longer used as recorded actual time. Only recorded Work Order / Daily Task minutes are counted as Recorded Time.

Tasks without complete Start and Deadline dates, and unlinked project work, remain visible but are excluded from Time Budget Used. No source record is altered.

## Deployment safety

Keep the existing Render build command:

```text
pip install -r requirements.txt && alembic upgrade head
```

Alembic will confirm the existing head and will not run a new Release 21.17 migration.
