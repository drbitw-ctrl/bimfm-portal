# Release 21.21.5

- Utilization reports now use a 0–200% visual scale with a marked 100% plan line.
- Projects and tasks can visibly exceed 100%, and over-plan duration is displayed.
- Assigned freelancers receive a reminder when an administrator changes a task from a non-completed status to Completed.
- Staff Access now includes a prominent current-account Task Assignment panel so Administrators can enable their own Task Supervisor mapping.
- No database migration is included.
