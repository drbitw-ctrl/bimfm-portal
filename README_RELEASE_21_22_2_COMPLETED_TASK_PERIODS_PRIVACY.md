# BIM Portal Release 21.22.2

## Freelancer privacy
Freelancer-facing Today's Attendance no longer displays the internal freelancer/member code. The profile card keeps the member name and join date. Internal codes remain available on administrator-only pages for operations and troubleshooting.

## Recently Completed Tasks period filter
The internal Recently Completed Tasks page now supports these periods:
- Last 1 Week
- Last 2 Weeks
- Last 3 Weeks
- Last 30 Days
- This Month
- Last Month
- Last 3 Months
- Last 6 Months
- All Completed Tasks

The filter is available on the shared staff portal used by Administrator, Supervisor, and Finance roles. All Completed Tasks remains the default so existing behavior is preserved until a user chooses a narrower period.

## Database safety
This is a code/template/localization-only release. No Alembic migration, schema change, backfill, or historical data rewrite is included.
